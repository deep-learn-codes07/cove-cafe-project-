# ☕ Cove Cafe Digital Menu

A modern, responsive, and real-time cafe menu management system built with HTML, CSS, JavaScript, Supabase, and Firebase Hosting.

## 🚀 Features

* Real-time menu updates
* Category & subcategory support
* Menu item images
* Responsive mobile-first design
* QR code menu access
* Search and filtering
* Admin dashboard
* Supabase Authentication
* Supabase Storage integration
* Firebase Hosting deployment
* Veg/Non-Veg indicators
* Bestseller badges
* Availability management

## 🛠️ Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript (ES6)

### Backend

* Supabase PostgreSQL
* Supabase Storage
* Supabase Authentication

### Hosting

* Firebase Hosting

## ⚙️ Setup

### Clone Repository

```bash
git clone https://github.com/yourusername/cove-cafe.git
cd cove-cafe
```

### Configure Supabase

Create a `.env` file:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_anon_key
```

### Deploy

```bash
firebase login
firebase init hosting
firebase deploy
```
